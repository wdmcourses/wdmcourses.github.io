Features

Everything you need to trim a video

Fast, focused and zero quality loss — KeyCut is built around the timeline.

Lossless by design

No re-encoding, no quality loss. Kept segments are spliced back together frame-perfect, so the output is identical to the source.

Cut on real keyframes

The caret snaps to the nearest keyframe, so every cut lands cleanly — no re-encoding is needed to make a cut exact.

Full timeline editing

Split, dim, restore and merge segments right on the timeline. Resize boundaries with a drag, select many with Alt + Click.

One-click export

All kept segments come out as a single file. Lossless copy, fast as your disk allows — no render queue.

Broad format support

Reads MP4, MOV, MKV, WebM, AVI, TS/M2TS, FLV and more — whatever your camera or OBS produced.

Portable, no install

FFmpeg is bundled. Extract the archive and run — nothing to install, nothing left behind.

Named markers

Drop colored markers on any keyframe and name each part. Jump between them with Ctrl+Shift+S / F — the layout is saved with the project.

Multi-export by parts

One click exports every marked part as its own lossless file — the marker name becomes the file name.

Disable any part

Flip a part off and it dims on the timeline, is skipped during playback and left out of every export.

Workflow

Three steps, done in a minute

Open a video

Drag & drop, or Ctrl+O. Keyframes are detected automatically.

Cut the parts you want

C to cut, X/R to dim or restore, V to merge blocks.

Export

Ctrl+E — kept segments become one clean file, losslessly.

Recording with OBS

KeyCut cuts only at keyframes — the frames that can be decoded on their own. The more keyframes a file has, the closer a cut can land to the exact frame you want.

If you record with OBS, make it write frequent keyframes for frame-level cutting precision:

In OBS go to Settings → Output, switch the output mode to Advanced, pick x264 (or x265) as the encoder and add keyint=6 to the encoder options. That writes a keyframe every 6 frames — about every 0.2 s at 30 fps, or 0.1 s at 60 fps.
  • Precision: cuts and deletes can land within a frame instead of jumping by whole sections.
  • Trade-off: a slightly larger recording, because every keyframe is an independently decodable frame.
